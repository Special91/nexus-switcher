## 2026-09-04 - Custom CSS Focus Outline
**Learning:** Keyboard navigation had no clear visual indicators for focused interactive elements (buttons, inputs, links) due to the lack of `:focus-visible` styling. Adding this rule globally using the primary theme color provides necessary accessibility feedback.
**Action:** Always include `:focus-visible` styling when defining custom buttons, inputs, and links in the design system to ensure accessible keyboard navigation without degrading mouse user experience.
