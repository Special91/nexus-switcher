## 2024-05-19 - Accessible Icon-Only Buttons and Focus Rings
**Learning:** In a vanilla HTML/JS Electron app heavily utilizing FontAwesome icons for buttons, icon-only buttons lacked `aria-label` attributes, making them inaccessible to screen readers. Furthermore, keyboard navigation was difficult without a clear `:focus-visible` ring. We learned that adding a global `:focus-visible` style combined with translating static ARIA labels using custom attributes (e.g. `data-i18n-aria-label`) and dynamic ARIA labels during DOM construction significantly improves accessibility.
**Action:** When introducing new icon-only buttons, ensure an `aria-label` is always added. For static HTML, use `data-i18n-aria-label` or hardcoded labels; for dynamic HTML constructed in JS, evaluate the string using the `t()` translation function. Additionally, rely on the global `:focus-visible` styles to indicate keyboard focus rather than assuming default browser outlines are sufficient.
